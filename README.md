# NEY QUIZ 1.0

Quiz desenvolvido em linguagem C para projeto acadêmico.

O programa funciona via terminal e possui perguntas de múltipla escolha, sistema de pontuação, controle de tentativas e menu.

---

# Funcionalidades

- Cadastro de nome do jogador
- Menu inicial
- Sistema de perguntas e respostas
- Alternativas A, B, C e D
- Controle de pontuação
- Controle de erros
- Encerramento automático após 3 erros
- Uso de funções
- Uso de arrays
- Uso de estrutura de repetição `for`
- Validação de respostas

---

# Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h`, `ctype.h` `string.h`

---

# Conceitos aplicados

Este projeto utiliza alguns conceitos aprendido em aula:

- Variáveis
- Arrays
- Strings
- Funções
- Estruturas condicionais (`if`)
- Estruturas de repetição (`for` e `do while`)
- Retorno de funções
- Entrada e saída de dados (`scanf` e `printf`)

# Como executar

## Compilar

```bash
gcc quiz.c -o quiz
```

## Executar

### Windows

```bash
quiz.exe
```

### Linux / Mac

```bash
./quiz
```
